# Trinoor email signature

Live page: https://trinoor.github.io/design-studio/signature/

- `index.html` - the page staff use to build and copy their signature (design: Option 02 Red Rail, Dulce)
- `assets/` - logo, contact icons and banners the signature loads (do not rename: sent emails point at these files)
- `photos/` - optional staff photos, see photos/README.md

To replace a banner or icon, upload a new file with exactly the same name. Every signature
already sent updates automatically. If the web address ever changes, update PUBLIC_BASE at the
bottom of index.html and ask staff to copy their signature again.
