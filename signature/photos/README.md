# Staff signature photos

One PNG per person, named after their Trinoor email address:

    sarah.oconnor@trinoor.com  ->  sarah.oconnor.png

Staff create the file on the signature page (Add my photo > Choose photo > Download my photo)
and email it to Design Studio. It is already cropped round at 288 x 288 px, so upload it as is:
on GitHub, open this folder, then Add file > Upload files.

The signature page finds the photo automatically within a few minutes.
This folder is public: only add photos people have sent in for their signature.
