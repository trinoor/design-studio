3Paste it into Outlook

Pick the Outlook you use. If there's a New Outlook toggle at the top right and it's on, or you use Outlook in a browser, pick the first tab.

  1. Click the Settings gear at the top right.
  2. Go to Accounts → Signatures.
  3. Click + New signature and name it Trinoor.
  4. Click inside the large box and paste: Ctrl + V (Windows) or ⌘ + V (Mac).
  5. Under Select default signatures, choose Trinoor for New messages and Replies/forwards.
  6. Click Save, then delete any old signature in the list.

New Outlook and Outlook on the web share one signature, so you only do this once.

  1. Go to File → Options → Mail and click Signatures…
  2. Click New, name it Trinoor, click OK.
  3. Click inside Edit signature and paste: Ctrl + V.
  4. On the right, set New messages and Replies/forwards to Trinoor.
  5. Click OK, then OK again.

Copy from Chrome or Edge. Pasting from other browsers can drop images in Classic Outlook.

  1. In the menu bar, click Outlook → Settings → Signatures.
  2. Click + and name it Trinoor.
  3. Click inside the editing box and paste: ⌘ + V. Save or close the editor.
  4. Under Choose default signature, set New messages and Replies/forwards to Trinoor.
  1. In the Outlook app, tap your profile picture, then the Settings gear.
  2. Tap Signature.
  3. Replace the text with the line below, then go back to save.

4Send yourself a test

Start a new email to yourself and check:

  1. The signature appears on its own.
  2. The logo, icons and banner show and aren't stretched.
  3. Reply to it from your phone. The signature underneath should stay intact.

If something looks wrong

Images show as empty boxes
Some email apps hide images until the reader clicks "Download pictures". That's normal.
Spacing or fonts changed
Delete the signature in Outlook, copy it again from this page and paste it without editing.
Two signatures appear
An old signature is still set as a default. Remove it in the same Signatures settings.
My details changed
Come back here, update them, and repeat steps 2 and 3.
